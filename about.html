About Courts After Dark

A university Design Thinking initiative transforming campus recreation and evening sports access.

Project Introduction

Courts After Dark is an interactive web platform prototype created as part of a human-centered Design Thinking project. The initiative focuses on bridging the gap between student interest in evening recreational sports and the logistical challenges of discovering available campus facilities.

Problem Statement & Motivation

During initial student user research, participants highlighted several recurring friction points regarding campus recreational sports:

  • Lack of centralized, easily accessible visibility into court schedules and facility details.
  • Uncertainty about evening hours and illumination conditions across outdoor venues.
  • Inconvenience of informal or paper-based coordination for casual games.
  • Difficulty finding open recreational time during high-demand evening hours.

Core Objectives

  • Discovery: Provide an intuitive, visual catalogue of sports facilities with clean photography and venue specifications.
  • Scheduling Ergonomics: Test simulated hourly slot selection (available, booked, maintenance states) to demonstrate transparent evening booking workflows.
  • Simulated Access: Enable instant demonstration requests stored in local device storage without backend server complexity.
  • Student Self-Service: Allow users to review and manage simulated bookings from a central dashboard.

Prototype Notice & Scope

Educational Prototype Disclaimer: Courts After Dark is an academic Design Thinking demonstration platform. All court schedules, availability indicators, and booking confirmations are simulated client-side using browser storage. This platform does not connect to live university administrative systems or guarantee physical court reservations.

Proposed Solution & Technology Stack

Courts After Dark provides a responsive, privacy-preserving client-side web application built with:

  • HTML5 & Semantic Web Architecture: Multi-page architecture optimized for accessibility and screen readers.
  • Modern CSS3: Custom design system utilizing Forest Green (#173F35), Sand Beige (#E8DCC5), and Electric Purple (#8B45F7), Inter typography, and fully responsive grid/flexbox layouts.
  • Vanilla JavaScript (ES6+): Modular client-side architecture governing state management, UI interactions, modals, toasts, and input validation without heavy third-party framework overhead.
  • Browser Storage API: Persistent client-side data handling via localStorage and sessionStorage.
